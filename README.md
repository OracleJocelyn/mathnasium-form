# Overview

This repository contains files for a functioning HTML intake form that collects student and family information for Mathnasium Center and stores form submissions in a Google Spreadsheet.

This repository uses:
- HTML
- CSS
- JavaScript
- Google Apps Script

Each file includes detailed, line-by-line documentation explaining its purpose and functionality.

# Steps

1. Clone the repository (download index.html, script.js, and styles.css).
2. Create a google spreadsheet and paste Code.gs into Apps Script.
3. Replace blank spreadsheet id with actual google spreadsheet id within Apps Script.
4. Deploy Apps Script and copy Web App URL link.
5. Assign scriptURL variable to 'copied link' within script.js.
6. Deploy the web application.
